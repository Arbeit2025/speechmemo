# speechmemo（発言メモ）

話した内容をその場でテキスト化してメモに残す、単一ファイル Flask の小さな Web ツールです。

## これは何をするもの？

- ブラウザの音声認識（Web Speech API）で話した内容をテキスト化し、メモとして保存します
- 録音開始／停止ボタン、認識結果のプレビュー（確定前の下書き表示）と編集欄、「メモを保存」ボタンを備えています
- 音声認識が使えない環境では、同じ欄に手入力して保存することもできます
- 保存済みメモは新しい順に一覧表示され、キーワード検索と削除ができます（日時は JST 表示）

## プライバシーについて

- **音声データ自体はサーバーに送信されません。** 音声認識はブラウザ側で行われ、サーバーへ送られるのはテキスト化された文字列だけです（保存ボタンを押したとき）。
- ただし、ブラウザの音声認識そのものはブラウザ提供元のサービスを使って処理される場合があります（Chrome の場合は Google の音声認識サービス）。気になる場合は手入力をご利用ください。

## 対応環境

- 音声認識は **Chrome 系ブラウザ（Chrome / Edge など）のみ**対応で、**HTTPS** のページでのみ動作します（Firefox / Safari では音声認識は使えませんが、手入力での保存は可能です）。
- ローカル起動時は `http://127.0.0.1`（localhost）でも音声認識が動作します。

## ローカル起動

```bash
pip install -r requirements.txt
python app.py
```

起動したらブラウザで http://127.0.0.1:5000 を開いてください。

## 注意（Render Free で運用する場合）

- メモは SQLite ファイル（`speechmemo.db`）に保存されます。**Render の Free プランではファイルシステムが永続化されないため、再デプロイや再起動でメモが消えることがあります。** 大事なメモは別途控えておいてください。

## テスト

```bash
python -m unittest discover -s tests
```

テストは一時データベースを使うため、実際のメモデータには触れません。

## 構成

- `app.py` … 本体（単一ファイル、Flask＋SQLite）
- `tests/test_app.py` … unittest
- `requirements.txt` … Flask / gunicorn のみ
